Brainstorm: 
Is a notetaking / ideacreating app. It allows users to work on multiple ideas and record them simultaneously including visualizing and connecting any secondary or supporting ideas. It has the following flow, each user can create multiple sessions (though this will be limited in its current stage), each session can have folders and folders usually contain cards. Below I will attach images of each view and how to navigate the site. This is available both to run on your local device by making your own changes to it or cleaning it up, as well as through the web via github pages at:{url}
{images for view}

When working on projects, assignments, or anything that requires both fast learning and effective application usually founded in not just one or two fundamental concepts but several, and sometimes it gets very difficult to see the relationship between different concepts or how different ideas might relate to each other and the significance each of them holds. Brainstorm by allowing customization of cards and the lines connecting them, enables a significant number of combinations unique to each user and session. 

It is a ongoing project and will slowly include more and more features. If you wish to learn more you may visit the Features page on the website. Feel free to explore other sections regarding limits before using your account, although there is a free tier of X amount of sessions and cards, you can upgrade or just move to local storage and using your own API keys for gemini, supabase, and other related librares mentioned in the .env.example.
